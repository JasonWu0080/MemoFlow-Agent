# Code of Conduct

[中文](CODE_OF_CONDUCT.zh-CN.md)

We want MemoFlow Agent to be a welcoming project for everyone, regardless of background or identity.

**Expected:** be respectful and constructive; assume good intent; give and accept feedback gracefully;
focus on what is best for the project and its users.

**Not acceptable:** harassment, insults or personal attacks; discriminatory language or imagery; sexual
attention or advances; publishing others' private information; sustained disruption of discussions.

**Scope:** all project spaces (issues, pull requests, discussions, chat) and public spaces where someone
represents the project.

**Enforcement:** report incidents privately to the maintainers (see SECURITY.md for the private contact
channel). Maintainers will review every report, keep reporters' identities confidential, and may remove
content, warn, or ban participants temporarily or permanently.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), which we
recommend as further reading.
